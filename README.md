# AltairClient

A starter Fabric mod for Minecraft Java Edition 1.21.11.

## Requirements

- Java 21 or newer

## Build

On Windows:

```powershell
.\gradlew.bat build
```

The remapped mod JAR is created in `build\libs`.

## Run in the development client

```powershell
.\gradlew.bat runClient
```

The mod entrypoint is `dev.altairclient.AltairClient`.
